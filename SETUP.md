# Kiyan Profile — Setup

This repository is intended to replace the contents of `kiyan-rahmati/kiyan-rahmati`.

## 1. Upload
Copy everything in this folder to the root of your profile repository.

Important:
- keep `README.md` in the root
- keep `assets/` in the root
- keep `.github/workflows/` in the root

## 2. Enable Actions
GitHub Actions must be allowed for the repository. The workflows:
- generate the contribution snake every day
- refresh recent public activity every 6 hours

The first run can be started manually from the **Actions** tab.

## 3. Why this is different from a normal README
The referenced Shivam profile uses many local animated SVG panels and automated GitHub-generated assets. This version follows that same architecture, but all identity/project information belongs to Kiyan.

## 4. Important
Do not add fake contribution numbers or fake activity. Stats shown by external services and the snake should come from GitHub data.
